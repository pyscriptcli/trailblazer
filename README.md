# Trailblazer Salesforce Knowledgebase

This repository is the growing Salesforce study and reference collection for **Dame**, a Salesforce-focused AI assistant persona. It starts with the Trailhead **Data Modeling** badge and its three lessons.

## Use Dame

Invoke the repository skill as `/dame` (or select the `dame` skill in a compatible agent). Ask Salesforce questions in plain language. Dame should search the relevant material in [`knowledgebase/`](knowledgebase/), then use current Salesforce or Trailhead documentation when the repository does not cover the question or the answer may have changed.

Skill instructions: [`.agents/skills/dame/SKILL.md`](.agents/skills/dame/SKILL.md)

## Adding more Salesforce topics

Keep material organized by Salesforce subject and, when appropriate, by Trailhead badge/module and lesson. Prefer concise original notes, decision aids, examples, and links to authoritative sources over copying whole third-party learning pages. Include source URLs and a checked/compiled date so readers can verify details that change.
