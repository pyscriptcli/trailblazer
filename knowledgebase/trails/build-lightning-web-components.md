# Build Lightning Web Components

**Type:** Trailhead trail study guide
**Checked:** 2026-09-28
**Audience:** Developers, intermediate

## What this trail covers

This developer trail takes roughly 11 hours and includes eleven steps, from a quick start and tool setup to component fundamentals, Salesforce data, testing, troubleshooting, communication, and interoperability with Aura and Visualforce. Lightning Web Components (LWC) are custom user-interface components built with standard web technologies and Salesforce platform services.

## Suggested progression

Set up the Salesforce CLI and editor workflow first. Learn component structure and data access, then test and troubleshoot components before studying inter-component communication. The Aura and Visualforce units help when working in existing orgs that combine older UI technologies with LWC.

Salesforce recommends using base components and platform APIs where they fit. Follow the [LWC Developer Guide](https://developer.salesforce.com/docs/platform/lwc/guide) for current component syntax, supported APIs, and platform constraints.

## Review prompts

1. What belongs in the HTML template versus the JavaScript controller?
2. How will the component obtain and update Salesforce data?
3. What behavior should be covered by tests?
4. How do components communicate, and what should own shared state?
5. Which current platform guide should you check before using an API or syntax feature?
