# Prepare for the Salesforce Administrator Credential

**Type:** Trailhead TrailMix and exam study guide
**Checked:** 2026-09-28
**Current credential name:** Salesforce Certified Platform Administrator

## How to use this guide

The linked TrailMix is an exam-preparation curriculum, not a single module. Its current page groups resources by exam domain and gives domain weightings that total 100%. Use the official [Platform Administrator certification page](https://trailhead.salesforce.com/en/credentials/platformadministrator) and its current exam-guide link to confirm the live blueprint before planning a test date; domains and resource links can change.

## Current domain map

| Exam domain | Weight | Suggested coverage from the TrailMix |
|---|---:|---|
| Configuration and Setup | 15% | Platform basics, org and user setup, identity, data security, permission set groups, and user preparation projects. |
| Object Manager and Lightning App Builder | 15% | Data Modeling, object customization, Lightning Experience customization, App Builder, formulas, and validation rules. |
| Sales and Marketing Applications | 10% | Accounts and contacts, leads and opportunities, campaigns, and sales paths. |

| Data and Analytics Management | 17% | Data Management, duplicate management, import/export, Data Loader, reports, dashboards, and folder access. |
| Automation | 15% | Automation tool selection, approvals, approval processes, screen flows, and Flow Builder basics. |
| Agentforce AI | 8% | Agentforce fundamentals and Agentforce Builder introduction. |

The resource grouping above summarizes the [TrailMix](https://trailhead.salesforce.com/users/strailhead/trailmixes/prepare-for-your-salesforce-administrator-credential); use its live page for exact units and the official exam guide for the current test objectives.

## Study plan

1. Read the exam guide and mark topics you can already explain versus topics to learn.
2. Study the weighted domains, spending more review time on the larger Data and Analytics domain while covering every domain.
3. Complete hands-on Trailhead projects in a practice environment, especially for users and access, object setup, reports, automation, and data operations.
4. Keep a list of concepts that depend on org configuration or have changed names, and verify them in current Salesforce Help.
5. Revisit missed questions by domain and explain the underlying admin decision in your own words rather than memorizing a click path.

The TrailMix also recommends the optional [Prepare for Your Administrator Certification Exam course](https://trailheadacademy.salesforce.com/classes/crt101-prepare-for-your-salesforce-administrator-certification-exam) (about eight hours; availability may vary).

## Review prompts

1. Which domain currently has the highest exam weight, and what are its main tasks?
2. How do object relationships, sharing, and permissions work together?
3. Which import method fits a one-time small file versus a larger or repeatable load?
4. When should an admin use a flow versus another automation tool?
5. How will you verify that an exam objective or Setup instruction remains current?
