## Quick mental model

| Salesforce concept | Database / spreadsheet analogy |
|---|---|
| Object | Table |
| Field | Column |
| Record | Row |
| Relationship field | Link between records in different objects |

An app's data model is the set of objects, fields, and relationships that define how its information is structured.

## Review checklist

- [ ] Explain standard versus custom objects.
- [ ] Identify identity, system, name, and custom fields.
- [ ] Pick suitable field data types for the data being stored.
- [ ] Explain the practical difference between lookup and master-detail relationships.
- [ ] Describe when a hierarchical relationship is available.
- [ ] Use Schema Builder to inspect a model and add an object or field.
- [ ] Use clear labels, descriptions, and required settings to keep data understandable and complete.
